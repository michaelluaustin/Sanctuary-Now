# **App Name**: Sanctuary Now

## Core Features:

- Topic Selection: Display a list of available worship session topics.  Each topic includes a title and short description. User should be able to select a topic to begin a worship session.
- AI Session Generation: Use a tool to Generate relevant Bible verses, reflections/analysis of each verse, and suggested worship songs (YouTube links or titles) based on the selected worship topic.
- Session Display: Display the AI-generated session content (Bible verses, reflections, YouTube videos, concluding reflection, and final prayer) in a structured and easy-to-follow layout.
- Favorites: Allow users to save their favorite sessions locally for easy access later. No login required.

## Style Guidelines:

- Primary color: Soft sky blue (#87CEEB) to evoke a sense of peace and tranquility.
- Background color: Very light desaturated blue (#F0F8FF), almost white, creating a clean and calming atmosphere.
- Accent color: Gentle lavender (#E6E6FA) to highlight important elements without being intrusive.
- Body and headline font: 'Literata' (serif) for a readable and spiritually informed feel.
- Simple, distraction-free layout with ample whitespace to enhance readability and focus.
- Use minimalist icons to represent different topics and functions within the app.
